### 1.5 段内数据长什么样（逐骨实测）

按 `elysia` 解析器同款布局（`[MDLE0002\0][u32 段尾偏移][u32 骨骼矩阵字节][每骨 64B]`）逐骨读出 127 个 64 B 矩阵：

| 指标 | 结果 |
|---|---|
| 骨数一致性（`MDLE` 矩阵数 vs `MDLS` 骨数） | **8/8 一致**（127 骨全部对齐） |
| **全零** payload 的模型数 | **0/8**（矩阵全部非零） |
| 与同下标 `MDLS` **局部** bind **逐字节相同**的骨 | **68 / 127** |
| 与 `MDLS` 局部 bind **不同**的骨 | **59 / 127** |
| 差异骨是否被网格蒙皮引用（`blendIndices` + 权重 > 0） | **是**：Rella 10/10、眼睛 1/1、m眼睛 1/1、girl 1/1、人物 18/20（2 个未被引用）、眼睛组合 5/6（1 个未被引用） |

**关键中立探针**：把 MDLE 校正 `corr[b] = World(MDLE)[b] · World(MDLS bind)[b]⁻¹` 作用到**静止顶点**上，
量每个顶点相对原网格的位移（**两种合成序都算**，避免约定之争）：

```

0917/3462491575  m眼睛        v=42  父先乘 {maxDisp:0.00} | 子先乘 {maxDisp:0.00}
dd/3544152633    girl         v=438 父先乘 {maxDisp:0.00} | 子先乘 {maxDisp:0.00}
dd/3554161528    人物         v=497 父先乘 {maxDisp:0.00} | 子先乘 {maxDisp:0.00}
```

## 3. 支持与反对"需要额外支持 `MDLE0002`"的证据

### 3.1 支持方（认为**需要**额外支持）的证据

1. **段真实存在且非平凡**：6 个不同 `.mdl`（`MDLV0023`）带该段；**0/8 全零**；骨数 8/8 与 `MDLS` 对齐（§1.5）。
2. **差异骨不是"死角落"**：59/127 个与 `MDLS` 局部 bind **逐字节不同**的骨里，**绝大多数被网格蒙皮引用**
   （Rella 10/10、眼睛 1/1、m眼睛 1/1、girl 1/1、人物 18/20、眼睛组合 5/6）⇒ 若上游把 MDLE 当绑定基准，理论上会改变姿势。
3. **第三方给出过"它是绑定姿势"的描述**：`references/vendor-ref`（`oneincase/webwallgl`，**MIT**，仅行为对照、非构建依赖）
   在解析层把该段描述为"**贴图空间的静止姿势**"，并给出实测：顶点按 `MDLS` 烘焙、而 UV 对应 MDLE 姿势；
   对案例 `lainpw` 用 `World(MDLE)·World(MDLS)⁻¹` 变换后，与 UV 反推的贴图坐标**误差为 0**。
   同一文件另一处注释把它称作"蒙皮的绑定基准（缺失时用 `MDLS`）"。
4. **我们自己的实现保留了解析**：说明当时认为该段"值得解析"（`elysia/we-renderer/puppet.js:481-500`）。

### 3.2 反对方（认为**不需要**额外支持）的证据

1. **一手中立实测（本页最强证据）**：把上述校正作用到**我们语料**的静止顶点上，位移 **≈ 0** ——
   6 个模型里 5 个 **< 0.01** 单位、无一顶点位移 > 0.5；唯一非零是 Rella 部件骨 6 的 **3.93** 单位（12/144 顶点），
   **两种合成序结论相同**（§1.5）⇒ 在我们语料上，"用 MDLS bind"与"用 MDLE"**给出同一结果**，"额外支持"没有可观测收益。
2. **同一份 vendor-ref 的蒙皮路径记录了实测反证**（`references/vendor-ref/.../render/mdl-skin.js:276-292`）：
   乘该校正会把案例 `lainpw`（模型 `3787341007`）的眼睛推离 **426 px / 360 px**、头发 **345 px**，
   而**不乘时顶点偏离原网格 0 px**；文中据此**明确要求不要乘**该校正，并佐证其本机唯一一直正常的 puppet
   （`3791428510`）**没有** MDLE 块。⇒ 该实现自己的行为结论是：**MDLE 不参与蒙皮**。
3. **`wer-ref`（GPL-2.0-only，只引用行为结论）**：`src/backend/scene/internal/parser/WPMdlParser.cpp:835,842` 校验
   "payload 字节数必须 = 骨数 × 64，否则**拒绝整个模型**"；`:1026` 分派到该段并登记为 `file_world_bind`
   （`has_file_world_bind = true`）。但它的测试**逐字**断言：
   `src/test/scene/mdl/puppet_semantics_test.cpp:101` → "**MDLE must not replace the validated MDLS root bind**"；
   `:185` → "**unset MDLE payload must remain observational only**"。⇒ 行为结论 = **记录/校验，但不用于绑定姿势**。
4. **`lwe-ref` 全树 0 命中**（根本不存在对该段的处理）。
5. **我们运行期 0 命中 + `b.extend` 只写不读**（§2）⇒ 现状不存在需要修的"半实现"。
6. 现状渲染**没有**已知的 MDLE 相关视觉缺陷报告（多个含 MDLE 的包在现行管线里正常出图）。

### 3.3 两方证据的对照

| 争点 | 支持方 | 反对方 | 本页采信 |
|---|---|---|---|
| 段是否存在、是否非平凡 | 6 文件、非零、骨数对齐 | — | **支持方**（事实） |
| 差异骨是否可能影响姿势 | 被蒙皮引用 | 校正位移 ≈ 0（我们语料） | **反对方**（一手实测优先） |
| 第三方是否"用它" | 曾被称为绑定基准 / 贴图空间静止姿势 | 同实现的蒙皮路径实测**禁止**用它；另两个实现不用于计算 | **反对方**（2:1，且反证是同源的实测） |
| 我们是否需要补功能 | 解析但未消费=潜在缺口 | 消费与否在我们语料上结果相同 | **反对方** |

## 4. 结论与判据

### 4.1 结论

**维持现状：不需要为 `MDLE0002` 增加额外支持（该段不参与计算）。**

三条理由，按证据强度排序：

1. **一手语料实测**：在该段存在时，"`MDLS` bind 基准"与"`MDLE` 基准"在我们语料上**静止结果等价**
   （校正位移 ≤ 3.93 单位 / 仅 1 个模型 12 个顶点；其余 < 0.01），两种合成序结论一致。
2. **三方行为结论一致**：`lwe-ref` 不解析；`wer-ref` 解析+校验但测试断言不得替换 `MDLS` root bind、未设 payload 仅作观察；
   `vendor-ref` 解析但在蒙皮路径**实测禁止**使用（乘它会把部件推出数百 px）。
3. **我方运行期零依赖**：bundle / `demo.html` 0 命中，`elysia` 的 `b.extend` 只写不读，无测试断言 ⇒ 不存在误用风险。

> **这不是"作废 / 根本不存在这个问题"**：段真实存在、数据非平凡、且被蒙皮引用。
> 结论只在"**我们的语料 + 我们的渲染路径上不需要额外支持**"这一层成立 —— 换语料或换上游证据都要重开（见 4.2）。

## 5. 未证实项（本页**没有**证明的东西）

1. **59/127 个差异矩阵的语义未证实**。一个**未证实的假设**（不作为结论）：它们是同一世界位姿的另一种局部参数化
   —— 依据是校正 `World(MDLE)·World(bind)⁻¹ ≈ I`，但本页没有字节级/上游证据。
2. **Rella 部件骨 6 的 3.93 单位位移**是数值分解残差还是真实校正，未证实。
3. **vendor-ref 的实测模型不在本机语料**：`3787341007`、`3791428510` 在本机 `allwallpaper` 下 `find` **命中 0** ⇒
   其"426 px / 345 px"等数字**不能**外推到我们的语料（只能作为方法学与反证方向的证据）。
4. **我们从未做过"开 / 关 MDLE"的真机 A/B 截图对照** —— 4.2-D 的结案条件因此尚未满足。
5. **命名口径冲突未解**：`wer-ref` 把该段登记为 `file_world_bind`（"世界绑定"），而本页探针显示其值多与**局部** bind
   逐字节相同、且与两种世界链合成序都**不**匹配。双方对 "world" 的定义差异未证实（可能一方是"文件里的世界绑定"、
   另一方是"运行时合成的世界矩阵"）。
6. **上游（官方引擎 / 官方 Web 版）是否使用该段**：本页**没有**官方来源证据，只有两个第三方实现的行为结论。
7. **`MDLE` 段头里的 "u32 段尾偏移" 字段语义未证实**：探针观察到它指向条目末尾附近（与段大小自洽），但本页不据此下任何结论。
8. **`MDLV0019` 的 14 个模型未被检查**是否也能带 MDLE（本页只在带 MDLE 的 8 条 `MDLV0023` 条目上做结论）。
