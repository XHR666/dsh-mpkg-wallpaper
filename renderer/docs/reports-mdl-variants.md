# MDL 变体判别审计（P-250，2026-10-07）：同一张壁纸该按哪版布局加载

## 0. 一句话
语料 **158 个 `.mdl`**（51 包）里其实有 **三种顶点布局**；修前 `findMdlVertexBlock` 只认两种 ⇒
**42 个文件完全解析不了**、**40 个被误判成另一种步长**（拿到垃圾网格）。本项补上第三种布局
（48B 静态 PBR）并写死判别规则；修后 **154/158 解析成功**，剩 4 个（2.87 MB 天空盒）如实拒绝不猜。

## 1. 三种布局（都有语料实证）

| 变体 | 步长 | 属性布局 | 语料量 | 从何判定 |
|---|---|---|---|---|
| 蒙皮网格（puppet） | **80B** | `pos3@0 + blendIdx4@40 + weights4@56 + uv2@72` | **67** | 文件里有 `MDLS` 段（骨架/动画） |
| `MDLV0016` 紧凑变体 | **52B** | `pos3@0 + blendIdx4@12 + weights4@28 + uv2@44` | **5** | 魔数 `MDLV0016` + 顶点块标签 `0x01800009` |
| **静态 PBR（本项新增）** | **48B** | `pos3@0 + normal3@12 + tangent4@24(w≈±1) + uv2@40` | **86** | 48 签名三项抽样全 1.00（见下） |

- 48B 布局的签名（`mdlStride48Signature`，抽样 ≤80 顶点）：**法线单位率**（`|n|-1|<0.1`）、
  **切线 w≈±1 率**（`||w|-1|<0.15`）、**uv∈[-0.05,1.05] 率** —— 语料 86 个文件三项均为 **1.00**。
- 魔数分布：`MDLV0023` 148 / `MDLV0016` 6 / `MDLV0019` 4；**有无 `MDLS` 与步长不一一对应**
  （86 个无 MDLS 的文件里 86 个都是 48B 布局；有 MDLS 的 72 个里 67 个 80B、5 个 52B）。

## 2. 修前的两个缺口（数字）

```
修前：parseMdl 成功 112 / 失败 46
  ├─ 46 个失败 = 42 个 48B 静态网格（无任何分支认它）+ 4 个 2.87MB 天空盒
  └─ 另有 40 个 48B 静态网格 **被误判成 80B**（`vb % 80 == 0` 巧合成立 ⇒ 位置过闸门、uv/blend 全垃圾）
```

## 3. 判别规则（写死在 `findMdlVertexBlock`，判据逐条钉住）

1. **有 `MDLS` ⇒ 一律 80/52，绝不走 48**。语料有 **4 个 puppet 同时满足两套签名**（48 解释下
   `blendIdx` 的小整数被读成 float ≈0，恰好落进 uv 区间）⇒ 蒙皮文件必须让**骨架**赢，否则顶点与骨架错配。
2. **无 `MDLS` 且 48 签名强**（nrm≥0.9 / tanw≥0.8 / uv≥0.9），且现有 80B 候选的 **uv 证据弱**
   （`uv@72` 命中率 <0.9）⇒ 用 48。
3. 其余保持原判 ⇒ 63 个蒙皮 + 5 个 `MDLV0016` 逐位不变（零回归）。

## 4. 修后读数（`tests/mdl-variant-dispatch-test.mjs`，13/0）

```
parseMdl 成功 154 / 失败 4
分支分布：stride-80 = 74、stride-48 = 75、mdlv0016-compact-52 = 5
带 MDLS 却判成 48 的文件 = 0
仍失败 = 4（全是 models/自制天空盒0[012]/*.mdl，2 866 891 B：uv 超出 [0,1]，按"不猜"拒绝）
```

48B 网格顺带解出 **法线/切线**（`mesh.normals` / `mesh.tangents`，其余布局零新增字段），
蒙皮字段给中性值（骨 0 / 权重 1）—— 与"未提供 blendIndices[i]"的既有兜底契约一致。

## 5. 仍未做 / 已知边界
- **4 个天空盒已解决（P-256，2026-10-07）**：它们是 **平铺 uv**（`v ∈ [0.06, 2.04]`，落在 [0,1] 的 46%），
  法线/切线判据全 1.00 ⇒ 接受判据改为「`uv ≥ 0.9` **或**（`uvFin ≥ 0.99` 且 `spread ≥ 0.05`）」后
  **158/158 全部解析成功**（分支分布 80:74 / 48:79 / 52:5）。

  `tail` 数十万字节）⇒ 本项只取首块（与改动前同口径），多网格合并/分组留作后续。
- `stride-48` 的**几何渲染**（模型层按网格画而不是按材质贴图画）未做；本项只解决"加载/判别"。
