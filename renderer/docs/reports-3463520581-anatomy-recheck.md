## 2. 增量读数（该报告离线手段未覆盖、工具新给出）

- **①③ 之外的第四条链：锚点随时间的走向可以离线复现。** 对 `hair kirito front` 取 `--t=3 / --t=6.9`：
  含锚 origin x 从 2736.83（t=0）→ 2729.93（t=3）→ 2730.38（t=6.9），即 **Δx ≈ −6.85 → −6.40**。
  该报告第 80 轮真机同相位读的是 (2737,199) → (2732,199)@t≈3.7 → (2730,199)@t≈6.9 —— **离线复算与真机逐点吻合**。
  这意味着"P-241 逐帧附件跟随已修好"这件事现在有了**不依赖浏览器的复算入口**（判据已进
  `tests/layer-anatomy-test.mjs` 的冻结值 + `--t` 实验可手工复跑）。
- **"静态"发层在数据层自带骨骼**：`HAIR BACK (BIG)` 与 `main hair back c2` 的 `.mdl` 自带 **2 骨**
  （227/1197、266/1455 顶点/索引，动画 0 段）；`kirito face` 7 骨 1 动画。数据上有骨架 ≠ 运行期被蒙皮 ——
  与第 70 轮"这些部件 `skin: null`"的真机读数互相印证：**"不跟随"不是数据缺失，是运行期没把静态附件层接进蒙皮**
  （该报告第 70/71 轮的定性，工具从数据侧再钉一次）。
- **锚点沿父链叠加**：`main hair back c2` 的总锚点 Δ=(155.252, −722.522)，比它父级 `HAIR BACK (BIG)` 的
  (23.868, −705.691) 更大 —— 父级锚点位移经子层局部变换**继续放大**（子层还有自己的锚点贡献）。
  该报告只给了单层锚点量；工具能给出"链上任一层的累计锚点位移"，这对判断"发梢 vs 发根谁的偏差更大"有用。
