WEwebLoader WEwebLoader · npm/仓库名 wallpaper-engine-web-loader · 浏览器端 Wallpaper Engine 壁纸渲染器（GPL-3.0-or-later）

不装 Wallpaper Engine、不装 Windows 依赖：一个静态服务器 + WebGL2 就能在浏览器里实时渲染 scene.pkg / .mpkg 场景壁纸，带离线 PWA、逐层调试与对账门禁。 本仓库不分发任何真实壁纸 —— 页面里默认载入的是我们自己用算术生成的那张合成样例。

在线版有什么 / 没有什么

线上是纯静态托管（GitHub Pages）：没有服务端、没有本机 Node 后端。 测试台会自己探测到这一点并优雅降级（不假装能用），不是"坏了"。

能力在线说明
渲染 scene 场景包✅WebGL2 全在浏览器里跑；默认载入合成样例
逐层调试 / 属性面板 / 滤镜 / 分辨率 / DPR / FPS✅纯前端
「选择文件夹」扫描本地壁纸✅纯前端读取，文件不离开浏览器
壁纸库列表 / 属性保存 / 删除 / 打开所在文件夹❌需要本机 Node 后端（/api/*），线上 404 ⇒ 控件置灰并写明原因
渲染器诊断流 /diag❌同上；诊断区置灰并给出原因
真实壁纸包 / 预览图 / 音视频❌ 故意没有本仓库不分发任何真实壁纸，线上也不会出现

完整的测试台（壁纸库、属性保存、诊断流）需要在源码目录跑本机 Node host： bash start-demo.sh / pnpm dev。见仓库 README 与 docs/ONLINE-DEMO.md。
