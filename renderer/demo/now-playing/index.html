NowPlaying

Bencho「Now playing」的移植件（①(P-138)）—— 组件本体照抄、注释逐字保留； 这里只是它的独立演示页。源码与说明见 demo/now-playing/README.md。

50 形状变化多快（50 = 原件调好的 460ms）
16 封面圆角；盒子的角 = 封面 + offset（同心）
盒子的发丝线 = 组件自己的 stroke 属性（取代 Bencho 的全局 [data-stroke="on"]）

看什么：点一下胶囊（或封面）→ 盒子从 260×78 长到 260×189，封面从 40px 走到 64px、 圆角两端同心；播放键是**画出来**的（暂停 ⇄ 播放是同一对四边形在变形），心跳只在"点亮"那一次。 本机无 GPU（软件渲染、约 1fps）⇒ 动效必须人眼看，见 README 的「需要人眼/真机」一节。
